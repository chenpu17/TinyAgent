# 用户指南

> TinyAgent 0.4.3 (headless). Type a task, or /help for the command list.

TinyAgent 是一个单文件的 AI 助手，本指南介绍日常用法。更多细节请参考 `docs/install-guide.md` 里的安装指南。

## 简介

用户只需要一份配置文件就能开始。首次使用前，请先完成登录：在终端执行 `tiny-agent login` 并按提示输入密码即可。

## 基本用法

## 启动对话

在终端运行 `tiny-agent --tui` 即可开始对话。如果忘记了密码，可以在账号页面的安全设置里重置。登录之后，你的会话记录会保存在本机。

## 配置文件

配置文件默认放在 `~/.config/tinyagent/config.json` 这个位置。它的字段说明见下表（本文只列出最常用的几项）：模型，端点和密码对应的环境变量名。

先安装，再配置；两步都完成之后才可以使用。

缓存用于加速重复请求。想清空缓存，运行 `tiny-agent cache clear` 这个子命令。

## 系统提示词

在配置里设置 `"system_prompt": "你是助手,请简洁回答使用者的问题"` 可以改变助手的回答风格，不设置则使用默认风格。

## 常见问题

## 如何重置密码

打开账号页面，选择重置密码（需要验证邮箱），然后按邮件里的步骤操作。

## 提示找不到命令

说明安装目录不在 PATH 里。把安装目录加入 PATH，或者直接用完整路径运行，例如 `/usr/local/bin/tiny-agent run "你好"` 这样的写法。

## 想重新开始

1. 备份会话目录。
2. 在账号页面重新登录。
3. 删除旧的配置文件，删除前先确认已经备份。
