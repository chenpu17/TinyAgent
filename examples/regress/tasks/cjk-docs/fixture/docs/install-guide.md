## 安装指南

本指南介绍 TinyAgent 的安装步骤.

### 系统要求

- Linux、macOS 或 Windows 10 及以上版本
- 可以访问模型服务的网络连接
- 一个有效的使用者账号(见用户指南)

##### 下载安装包

从发布页面下载对应平台的二进制文件,放到 PATH 中的某个目录,例如 `/usr/local/bin` 这样的位置.下载完成后先校验文件:运行 `sha256sum tiny-agent-linux-musl` 并与发布页给出的摘要比对.

###### 写入配置文件

新建 `~/.config/tinyagent/config.json` 这个文件,填入模型名称和服务端点.记得先用 `export GLM_KEY=...` 设置口令,不要把口令直接写进配置文件.

### 验证安装

运行 `tiny-agent run "你好"` 应当能得到一句回复.如果收到了回复,说明登入成功.

## 常见安装问题

- 提示找不到命令:说明安装目录不在 PATH 里,请检查下载安装包这一节.
- 响应很慢:第一次请求需要预热,之后的请求会命中高速缓存.
- 返回 401:口令不正确或已经过期,重新设置后再试.

# 故障排除

如果以上步骤都没有解决问题,请收集日志(位于 `~/.cache/tinyagent/log` 目录)并反馈给维护者.
