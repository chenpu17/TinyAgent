## 3. 关键发现（进设计/实现的知识）

1. **glm 在 max_tokens=512 下思考烧穿→空输出**（M0 报告预言的模式在路线①
   复现：complaint 类推理最重，31s、512 out、零可见文本）。外层 2048 后正常。
   → M3 的 LlmTool 若外层模型也走内层通道，max_tokens 预算必须计思考余量；
   "空输出=预算不足"要按 A-L2b 的未知/无效口径区分于词表违规。
2. **朴素基线最弱**：glm 默认温度非确定性明显（p1 与 p2/p3 差 0.04 F1），
   且无效输出集中在此路线。temperature=0 的内层 deepseek 三轮极稳
   （0.959/0.970/0.971）——LD-4 的确定性调用设计被数据支持。
3. **库覆盖 78%**（224/288），覆盖精度 holdout 保持 100%（dev 亦 100%，
   但模板池同源，真泛化待 V0-B）。剩余 22% 边界项交给便宜模型，
   "代码接管明确项、模型判边界项"的分工主张成立。
4. **E3 负例的内外层差**：glm 24/24 全 unsure；deepseek 对逃过库结构性
   过滤的负例（含中文的营销/通知）仅 58%（7/12 误判为业务类）。
   → 内层的"拒答质量"弱于外层，正是质量政策里"升级换模型"该盯的位置
   （配方 C4 预登记了该升级路径）。库的结构性过滤（无 CJK）拦掉另一半。
5. **调优成本记录（D5）**：校准 2 轮（库规则）+ 外层 max_tokens 修正 1 次，
   计 ~40 分钟；冻结后 E1 零维护。模拟人工审批 10 分/路线照配方计入。

## 5. E1 分布移位的诚实说明

E1（seed 20260922）四路线 F1 不降反升。原因：实现里的 ±15% 权重微移主要
把大档降为中/小档（更短更简单），移位方向**偏易**。结论只能写"轻度分布
漂移下冻结库零维护守住门槛"，不能写"抗分布变化"。更严的移位（新模板池/
新噪声型）留 V0-B。
