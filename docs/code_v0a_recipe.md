# V0-A 预登记配方 v1（草案 · 待拍板冻结）

> 实例化的模板（模板文件 `code_v0a_recipe_template.md` 已随开源清理移除），对应 `code_llm_design.md` §8.1/§8.2/§9 V0-A 行。
> 状态：**草案**——§拍板项经确认后提交入库即冻结；冻结后不得按留出集成绩改门槛，
> 开发集只允许一次校准轮。数据来源：合成工单基准（生成器规格见 A2）。
> 模型与网关数据来自 2026-09-21 真实网关冒烟（`code_m0_probe_report.md` §6）。

## A. 任务族与数据

| 项 | 值 |
|---|---|
| A1 首发任务族 | **只读工单分类/打标**：输入 = 工单（标题+正文），输出 = 单标签。封闭词表 7 项：`bug`(故障报告)、`feature`(功能请求)、`account`(账号问题)、`billing`(计费问题)、`howto`(使用咨询)、`complaint`(投诉/升级)、`unsure`(无法可靠分类——乱码/空内容/多类混杂) |
| A2 语料来源与版本 | 程序化生成器 `scripts/v0a_ticket_gen.py`（规格：每类模板池 ≥8 变体 × 同义改写 × 噪声注入），**版本 = 生成器 commit + seed**。首版 seed=20260921 |
| A3 开发/留出分割 | 总量 **480 条**：4 头类（bug/feature/account/howto）各 **84** + 2 少数类（billing/complaint）各 48 + unsure 48。（勘误 2026-09-21：草案原文"各 96"求和为 528≠480，按冻结总量 480 与少数类 10% 比例修正为 84；阈值未动。）开发集 192（头类 33/少数类 19/unsure 22）/ 留出集 288（51/29/26），按类分层、种子交错切分；开发集用于起草库与唯一一次校准，留出集只在冻结后跑 |
| A4 规模分层 | 小（≤80 字）/ 中（80–200 字）/ 大（200–500 字，含问候语、系统签名、重复粘贴等噪声）三档，各类内均匀 |
| A5 少数类定义 | `billing`、`complaint`（各占总数 10%）；覆盖率按类单独报，不只报宏平均 |
| A6 独立判卷 | 判卷脚本 = 生成器真值全量比对（零人工、可复现）；业务标准 = A1 分类定义 v1。**真值审计**：每路线随机 30 条人工语义复核，防生成器 bug 造成假真值 |

## B. 模型与网关

| 项 | 值 |
|---|---|
| B1 外层模型 | `glm-5.3-flash`（agent 发现/修订需更强推理；冒烟 5.3s/轮，V0-A 外层轮数少可接受） |
| B2 内层模型 | `deepseek-flash`（批量单发判卷；冒烟 1.3s/条，reasoning 开销小） |
| B3 价格存档 | 测试网关不按 token 计费 → **主口径用 token 与时延**；货币折算按公开价目另附（快照日期与单价跑前补录）。计价口径：只按 completion 计（reasoning ⊂ completion，勿重复计，见 M0 报告 §6） |
| B4 缓存规则 | 记录缓存命中与首轮用量（该网关 cache 恒 0，照记）；比较一律用未命中口径 |
| B5 失败与重试 | 429/5xx 重试 1 次、间隔 5s；重试与最终失败**保留在结果里计入分母**，不换种子重跑；网络/超时按 `timeout` 归属单列 |

## C. 质量政策（先于数据冻结）

| 项 | 值 |
|---|---|
| C1 通过阈值 | 宏 F1 ≥ **0.85**（7 类含 unsure；逐层、逐类另报）；主指标 = 留出集 3 次重复的均值 |
| C2 覆盖率底线 | 有效输出率 ≥ **98%**（拒答/解析失败/空输出计分母）；少数类各类召回 ≥ **0.75** |
| C3 三层验证分开 | ① 自测=纯断言（真值全量比对即自测，全覆盖）；② 固定探针 verify(n)=每路线 8 条哨兵工单的链路健康检查；③ 本批独立抽检=A6 的 30 条真值审计 |
| C4 抽检比例与升级 | 每路线 30 条（分层随机）；真值错误 ≥3 条 → 该批次作废、修生成器、开发集重出（留出集阶段发现只记录不挪门槛）；输出质量异常 → 按预登记换模型（内层 deepseek→glm）一次，不静默重跑 |
| C5 部分交付 | done≠verified；中断按已判卷条数出部分报告并标注未判条数，无结果丢失后冒充完整 |

## D. 成功判据与门槛（四路线同口径）

| 项 | 值 |
|---|---|
| D1 四路线 | ① 外层逐条（glm，每条独立 run，无库）② 外层+纯代码库（词典/规则处理明确条目，模糊条目回落外层）③ ②+内层单发（模糊条目由库脚本调 deepseek，labels=A1 词表，temperature=0）④ ③+批内并行（线程池有界波模拟 callBatch）。各路线同等业务知识（同一分类定义文档）与同等调优机会（同一 D6 预算） |
| D2 单位成功成本 | token/正确条（输入/输出分列）+ 秒/正确条；全失败条目计入分母，全部失败的路线不定义该指标只报失败率 |
| D3 成本门槛 | ③ 的单位 token 成本 ≤ ① 的 **50%**（库摊销主张）；④ 相对 ③ 的门槛在时延非 token（见 D4） |
| D4 时延门槛 | ④ 整批（288 条）墙钟 ≤ ① 的 **50%**；单条 P95 ≤ 30s |
| D5 人工工时 | 各路线记录调优/维护分钟数（V0-A 以实际执行耗时近似，人工审批环节模拟为固定 10 分钟/路线） |
| D6 调优预算 | 每路线 ≤ **5 轮**迭代 或 ≤ **5M token**，先到为止；用尽即按当轮成绩报告，不得追加后继续比较 |
| D7 重复次数 | **3 次交错重复**（同配方、同留出集，路线交错执行）；报告均值与最差-最好区间；重复不替代独立样本 |
| D8 TCO 假设 | V0-A 不折算 TCO（无真实维护频率）；token+时延口径留 V0-B 补 |

## E. 变化任务条件（V0-A 占位）

| 项 | 值 |
|---|---|
| E1 新输入分布 | V0-A 做一轮：换 seed=20260922 重生成留出集（模板池抽样权重微移 ±15%），冻结的库与门槛原样跑 |

| E4 记录字段 | 正确复用/必要修订/正确放弃/误用/维护时间，逐路线填报 |

## F. 结论出口（预登记）

- ①+③+④ 全部达 C1/C2 且 D3/D4 达标 → 允许进 M1～M3 最小实现。
- 质量达标但经济性未达 → 「证据不足」或「缩范围」（只保留 include 纯代码臂 ② 若其独立达标）。
- 质量未达 → 停止；② 若独立达标可单独评估保留。
- 报告必须写明：临时装置局限（③④ 为脚本模拟非 native）、真网关为测试网关、货币口径未折算。
