# V0-A 预登记配方 · 待填模板

> 对应 `docs/code_llm_design.md` §8.2「预登记配方与任务变化」与 §9 V0-A 行。
> 用法：场景负责人在**正式开跑前**填齐下表数值并冻结（提交入库即冻结凭据）。
> 冻结后**不得按留出集成绩改门槛**；允许用开发集校准一次；样本不足或区间
> 无法区分时，结论只能写「证据不足」，不强行判胜。数值由首发业务场景和
> 可接受服务标准确定——本模板不提供默认值，防止"先跑后定靶"。

## A. 任务族与数据

| 项 | 待填 | 说明 |
|---|---|---|
| A1 首发任务族 | ＿ | 只读工单分类/打标/字段抽取/合规检查中选一；给出业务定义 |
| A2 语料来源与版本 | ＿ | 数据集路径/commit/日期；冻结后换数据=新配方 |
| A3 开发集 / 留出集分割 | ＿ | 条数与切分方式（按时间/按来源交错）；**测试分割防止 warm 库从留出答案中生成** |
| A4 规模分层 | ＿ | 如 小(≤200 字)/中/大 各 N 条；每层单独报表 |
| A5 少数类/长尾定义 | ＿ | 哪些类或字段算少数类；覆盖率底线按类给，不只给宏平均 |
| A6 独立判卷标准 | ＿ | 判卷人/判卷脚本与业务标准版本；判卷者不得参与调参 |

## B. 模型与网关

| 项 | 待填 | 说明 |
|---|---|---|
| B1 外层模型 | ＿ | 名称/网关/价格快照日期 |
| B2 内层模型（增强臂） | ＿ | 同上；普通脚本臂不消耗模型 |
| B3 价格存档 | ＿ | 每 1M token 输入/输出单价 + 计价口径说明（避免重复计入 output 内含的 reasoning） |
| B4 缓存规则 | ＿ | 预登记：记录缓存命中与首轮用量；是否启用缓存、如何计价 |
| B5 失败与重试规则 | ＿ | 网关失败保留并按本规则另报，不事后删除；429/5xx 的重试次数与间隔 |

## C. 质量政策（先于数据冻结）

| 项 | 待填 | 说明 |
|---|---|---|
| C1 通过阈值 | ＿ | 主指标（如宏 F1/逐字段准确率）≥ ＿；分层数值可不同 |
| C2 覆盖率底线 | ＿ | 输出覆盖率（拒答/ unsure 计分母）≥ ＿；少数类召回 ≥ ＿ |
| C3 抽检政策 | ＿ | 自测（纯断言）/ 固定探针 verify(n)（链路健康）/ 本批实际输出独立抽检——三者分开记 |
| C4 抽检比例与升级路径 | ＿ | 每批抽 ＿；抽检失败触发既定升级（换模型/升人工），不允许静默重跑 |
| C5 部分交付政策 | ＿ | done≠verified；中断按 checkpoint 交付，未落盘标待确认 |

## D. 成功判据与门槛（四路线同口径）

| 项 | 待填 | 说明 |
|---|---|---|
| D1 四路线定义 | 参照 §8.1 | ① 外层逐条 ② 外层+预置库(纯代码) ③ 外层+库+内层单发 ④ ③+callBatch；各路线同等业务知识与调优机会 |
| D2 单位成功成本 | ＿ | 元/正确条：模型费与工时分列；全部失败/重试/复核计入，全失败任务族不定义 |
| D3 成本门槛 | ＿ | ③/④ 的单位成功成本 ≤ ① 的 ＿% 且质量达标 |
| D4 时延门槛 | ＿ | 单条 P50/P95 与整批时限 |
| D5 人工工时门槛 | ＿ | 含发现/修订/审批/维护的分钟数/百条 |
| D6 调优预算 | ＿ | 每路线最多 ＿ 次迭代/＿ 元模型费；用尽即停，不得追加后继续比较 |
| D7 重复次数 | ＿ | ≥3 次交错重复；重复不替代独立任务样本 |
| D8 工时单价与 TCO 假设 | ＿ | 折算总成本用的时薪与复用假设（如 月 ＿ 条、库改版 ＿ 次/月） |

## F. 结论出口（预登记，不许临场改）

- 达标 → 允许进入 M1～M3 最小实现（§9 投入门）。
- 未达标但接近 → 记录差距与原因，「证据不足」或「缩范围」二选一。
- 明显未达标 → 停止；纯函数 include 若独立有收益可单独评估保留。
- 原型成绩**不代表** native 集成成本（§9 V0-A 行原文），报告须写明临时装置局限。
