# run_code v3：同次完成闭环探针

日期：2026-09-11。实验版本：`run-code-routing-v3`。

结论：官方判卷通过，但未减少模型往返，代码生成和错误恢复成本上升；**v3 不提升为当前默认候选，已恢复 v2 提示词和指纹**。实验提示词逐字归档在 `examples/prompts/experiments/agentic-code-v3.md`。

本次只改变模型可见的一个因素：在 `agentic-code.md` 增加一段同次执行纪律。工具描述、teaser、技能全文、运行时和实际 release 二进制均与 v2 逐字节一致；没有增加宿主触发规则，也没有修改 no-code 的 `agentic.md`。

## 改动与自检

规则与响应形状已明确、修改已授权且预算足够时，同次 run_code 完成收集、KEEP/ACT 检查、执行、独立读回及对不应改变状态的校验。仅在新信息需要模型判断/用户确认、预算边界或不确定结果需要调查时拆分；不为叙述阶段进度而返回。

自检确认：保留“修改前检查、修改后独立读回”的顺序，保留语义判断和用户确认边界，保留异常与资源限额分批路径。没有用强制“一次调用”覆盖未知接口、授权不足或预算不足的情形。

`scripts/sync_run_code_contract.py --write/--check` 固定当前提示词和版本；程序化比对 v2 的 `pilot.json` 确认除变体提示词外所有模型可见契约字段一致，二进制 SHA256 相同。本轮没有 Rust 实现变化，不重复将既有 Rust 测试包装为新增验证。实际行为以这次模型轨迹及官方状态判卷验证。

## 实验条件

- 模型：`glm-5.3-flash`；任务：awclean，一次；on-demand、precheck=false。
- 独立实验臂：`ta-code-routing-v3-aw`，不覆盖 v1/v2。
- binary SHA256：`7872a3788036e0f673cbec2b0e9219f42c8ed0a30697d27cf5b19641daa94622`。
- code prompt 文件 SHA256：`fe905668c59520fcea0b7b298499229a180f4b11d31a60b34bbb0cde0d65a8f2`。
- 使用既有任务、工具集合、执行器和官方状态判卷，不改 benchmark 源文件。

```sh
python3 scripts/run_code_routing_pilot.py --tasks awclean --run
```

以上为实验时命令。当前已恢复 v2，直接重跑会按当前 manifest 选择 v2，不能当作 v3 复现；v3 复现需使用归档提示词并恢复该臂 pilot.json 中的完整指纹条件。

原始数据：相邻仓库 `TinyAgentBench/results/runs/ta-code-routing-v3-aw/awclean/r1/`；实际条件归档在该实验臂 `pilot.json`。

## 结果

| 指标 | v2 | v3 |
|---|---:|---:|
| 官方判卷 | PASS 6/6 | PASS 6/6 |
| 模型轮次 | 10 | 11 |
| 总 token（含缓存输入） | 313,449 | 322,689（+2.9%） |
| 非缓存输入 | 38,620 | 34,233（−11.4%） |
| 输出 token | 8,397 | 10,632（+26.6%） |
| 客户端耗时 | 276.1s | 258.7s（−6.3%） |
| run_code 调用 | 3 | 5 |
| run_code 错误 | 0 | 1 |
| 生成 JS 字符合计 | 5,595 | 12,968（+131.8%） |

`cheat_flags` 为空。统计保存于 `docs/run_code_routing_v3_results.json`，没有隐藏首次失败或仅记录成功的程序。

模型读取技能后直接生成约 4.4K 字符程序，假设条目字段是 `.id`，实际需要 `song_id` / `album_id`；第一次只读调用后抛出 `item without id in song_library`，没有业务修改。它随后增加只读形状探查，再收集并保存计划，另一次代码执行 19 项修改及验证，最后又运行了一次无内部工具调用的程序。没有形成预期的单次闭环。

这是“过早生成长程序、随后恢复分阶段执行”的观察，并不能证明由新增段落单独造成；同模型采样差异也可能参与。耗时小幅下降同时伴随输出、代码量和轮次上升，不满足这次预先明确的“减少模型往返”目标，因此不因一个指标较好而保留该候选。

自检与收尾：归档提示词 SHA256 与实际实验记录一致；恢复后的 `agentic-code.md`、manifest 全部与 v2 pilot.json 一致；契约同步与 diff 空白检查通过。本次只改提示词与文档，无 Rust 实现变更。

下一步更值得检验的是“先用短小、可复用的取数程序建立已知字段和分页契约，再执行批量”，并考虑压缩长手册、减少示例通用框架的迁移。但不应为此次单例直接增加通用 `.id`/`song_id` 猜测或宿主自动解包。需要新版本、固定条件和多次重复验证，不能继续叠加规则后择优报告。

一次探针只能提供方向证据，不能把服务时延、采样差异或任务特例当成稳定因果收益。当前保留 v2 作为后续实验起点，不代表 v2 已在跨任务重复评测中胜出。
